# CmdTab showcase media

This directory contains a privacy-safe product showcase prepared on July 21, 2026.

## Source boundary

- `radial-menu-poster.webp` and `radial-menu.mp4` are authentic renders of CmdTab's production SwiftUI/AppKit Radial Menu using controlled fixture windows.
- The overview and Quick Actions clips, and the Classic Grid and Command Palette posters, are deterministic product composites based on the current production geometry, styling, item model, and documented behavior contract.
- No asset is an AI-generated product screenshot.
- No asset records a developer's or user's private desktop.
- The media demonstrates presentation and interaction concepts. It is not evidence that Accessibility, Screen Recording, Spaces, displays, fullscreen activation, signing, notarization, or exact focused-window acceptance passed on a signed installation.

## Delivery

The three MP4 clips are silent H.264 files with fast-start metadata. Posters use WebP. Canonical facts and test boundaries remain on the public Showcase and Evidence pages.
