# CmdTab HD showcase media

This directory contains a privacy-safe HD product showcase reviewed on July 22, 2026.

## Quality contract

- Every poster is 1920 × 1200 WebP.
- Overview, Radial Menu, and Quick Actions are silent 1920 × 1200 H.264 MP4s at 30 fps.
- Videos use fast-start metadata for web playback.
- Classic Grid and Command Palette remain poster-only until separate motion is reviewed.

## Source boundary

- Every asset is a deterministic HD product composite generated from vector source based on CmdTab's current production geometry, styling, item model, and documented behavior contract.
- Controlled fixture windows replace private desktop content.
- No asset is an AI-generated product screenshot.
- No asset records a developer's or user's private desktop.
- The showcase demonstrates presentation and controlled interaction concepts. It is not evidence that Accessibility, Screen Recording, Spaces, displays, fullscreen activation, signing, notarization, latency, memory, architecture, processor support, or exact focused-window acceptance passed on a signed installation.

The canonical facts and test boundaries remain on the public Showcase and Evidence pages.
