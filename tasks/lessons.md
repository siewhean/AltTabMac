# Lessons

- 2026-04-23: Separate hover-for-click-targeting from hover-for-selection; if users do not want the selector to chase the pointer, keep `hoveredIndex` for clicks but never write hover directly into `selectedIndex`.
- 2026-04-23: If the initial switcher selection jumps under a resting cursor, the fix is to suppress hover on reveal and only unlock it after the first real mouse-move event; clearing the hovered index alone is not enough.
- 2026-04-23: If a visible switcher refuses to scroll on the trackpad, check the global event tap before the SwiftUI view tree; swallowing continuous scroll at the CGEvent layer prevents the panel’s scroll view from ever seeing the gesture.
- 2026-04-23: If the switcher always shows a skeleton on first reveal, the problem is usually architectural rather than visual; a purely asynchronous two-phase preview pipeline guarantees placeholder exposure on cold start unless you synchronously prime at least the first visible thumbnails.
- 2026-04-23: For mouse-driven switcher UIs, passive `.onHover` residency is too coarse when the content itself scrolls; use movement-driven hover updates for selection, and let wheel events reach the scroll view instead of intercepting them at the window layer.
- 2026-04-23: In the classic grid, readability improvements should come from proportional icon/title scaling in the existing bottom label row; changing only font size without the icon and spacing makes the tile look mismatched.
- 2026-04-23: If a tile is in a true skeleton state, do not mix in app identity chrome; showing icons, labels, or "preview unavailable" copy makes the fallback look half-broken instead of intentionally unresolved.
- 2026-04-23: When aspect-fitting previews inside fixed tiles, the letterboxed area is part of the design, not dead space; it should inherit the switcher’s glass treatment, and true no-preview states should remain visibly skeletal rather than masquerading as complete thumbnails.
- 2026-04-23: AltTab-style aspect-ratio handling is not mixed-height tiles; the stable approach is to keep the tile frame fixed and aspect-fit the preview inside bounded thumbnail dimensions.
- 2026-04-23: Window thumbnails and activation trust do not need to share the same source of truth; when AX cannot safely identify a switchable window, you can still use a best-effort CG candidate for preview-only rendering while keeping activation at the app-fallback level.
- 2026-04-23: Once window enumeration degrades to app-level fallback or previewless entries, the classic grid must switch to an app-centric tile treatment; reusing a fake window skeleton makes the fallback path read like a rendering bug.
- 2026-04-23: Do not let `nil` mean both `no AX restriction available` and `AX failed to resolve any trusted windows`; switcher enumeration needs an explicit policy so unresolved AX window IDs can safely degrade to fallback app tiles instead of leaking arbitrary CG surfaces.
- 2026-04-23: Exact `CGWindowID` deduplication is not enough for macOS switchers; some apps expose several overlapping layer-0 surfaces for one visible window, so add a same-app semantic pruning pass based on overlap and center distance.
- 2026-04-23: When window captures are already pre-cropped for presentation, switcher thumbnails should render with fill-and-clip in the card frame; using fit reintroduces visible framing and malformed tile composition.
- 2026-04-23: When exact frontmost AX window identity is temporarily unavailable for an app with multiple visible windows, use the most recent visible same-PID history identity before returning `nil`; otherwise MRU ordering silently stops moving the active window to the end.
- 2026-03-27: For deterministic hotkey hold delays, carry the original event tap timestamp through async main-queue handling; sampling uptime later on the main queue reintroduces variable delay under load.
- 2026-03-27: For delayed hotkey overlays, ignore repeated hidden keydowns on deterministic paths; otherwise auto-repeat can silently stretch the reveal threshold.
- 2026-03-27: Accessibility close operations do not expose a `kAXCloseAction`; close windows by pressing the `kAXCloseButtonAttribute` instead of inventing a direct AX action constant.
- 2026-03-27: When a testable state machine keeps private helper structs, keep the exposed stored properties private too; Swift will reject an internal type that surfaces private-type-backed state.
- 2026-03-27: If a feature is only accessible through hidden shortcuts or buried implementation details, users will treat it as missing; surface shipped features explicitly in Settings and on the marketing site.
- 2026-03-27: For marketing-site motion, start with CSS-first reveal primitives and ambient keyframes, and always keep `prefers-reduced-motion` as a first-class constraint instead of bolting it on later.
- 2026-07-16: When adding a CGEvent tap handler for a new event type, update the tap’s event-interest mask in the same change; an implemented switch branch is inert unless the tap subscribes to that event.
- 2026-07-16: Do not compare raw `CGEvent.location` values with `NSWindow.frame`; normalize through `NSEvent.mouseLocation` or an explicit Quartz-to-Cocoa conversion before hit-testing AppKit windows.
- 2026-07-16: Dismissing a hotkey-driven overlay must clear its pending trigger state before the modifier release arrives; hiding the panel alone can turn the release into an unintended quick-switch action.
- 2026-07-16: Cold-start thumbnail priming must enrich the complete enumerated item list rather than replace it; capture readiness must never determine which active apps appear in the first switcher session.
- 2026-07-17: Do not infer duplicate windows from title, frame, or overlap when the product contract is window-level switching; only repeated records for the same stable `ownerPID + CGWindowID` may collapse.
- 2026-07-17: On macOS 14+, do not fall through from a bounded ScreenCaptureKit failure into synchronous private or Core Graphics capture APIs; those paths can block indefinitely when ReplayKit is unavailable.
