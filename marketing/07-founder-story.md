# Founder story

Written from the founder's own words (2026-10-10). Contact address everywhere: `trycmdtab@gmail.com`. Do not add claims beyond these (no user numbers, no "daily" release cadence unless true).

## Main version (website About page, launch email, press kit)

> I switch between a lot of windows on my Mac every day, and Cmd+Tab only switches apps. I tried the existing window switchers, but each had problems I couldn't fix or add to myself. So I built CmdTab, with the features I wanted.
>
> It's still in private beta and I'm improving it often. I'm sharing it with other Mac users in the hope it solves the same frustrations for them. If something doesn't work for you, tell me at trycmdtab@gmail.com and I'll fix it.

Live on the site: `/about`, section "Why I built CmdTab".
