## Decision boundary

This branch is not accepted by source presence or unit tests alone. It may become production-ready only when the same commit passes:

1. `scripts/release/verify-five-feature-source.py`;
2. focused feature tests;
3. the complete Swift package suite;
4. the Phase 1 deterministic packaging regression gate;
5. the packaged-app manual matrix generated by `run-five-feature-qa.sh`;
6. exact-window focus verification on supported macOS versions;
7. explicit degraded-mode verification when a private workspace capability is unavailable or changes semantics.

Any wrong-window activation, silent item omission, ambiguous durable-history match, unsupported action appearing successful, native-switcher bleed-through, or unlabelled workspace inference is a release blocker.

## Implemented source boundaries

### Minimized windows

- shared Accessibility catalogue keyed by `(PID, CGWindowID)`;
- minimized state and exact Accessibility element lookup;
- opt-in global and per-profile minimized membership;
- exact restoration of only the selected window;
- post-activation exact focused-window verification;
- placeholder preservation when preview capture is unavailable.

### Spaces, fullscreen, displays, and Stage Manager

- dynamically resolved managed-space membership and current-space metadata;
- fullscreen state and fullscreen-space modelling;
- display identifiers attached to workspace identities;
- capability states: available, degraded, unavailable, and failed;
- managed-space activation when the verified private symbols are present;
- explicit Stage Manager degradation because active/hidden-set identity is inferred rather than represented as a supported public identifier;
- exact focused-window verification remains authoritative after activation.

### Shortcut profiles

- versioned profile document;
- native AppKit shortcut recorder;
- forward/reverse shortcuts;
- hold-to-release and press-to-toggle session behaviour;
- per-profile style, visibility, minimized policy, display placement, and application filter;
- duplicate, reserved, invalid, and no-enabled-profile validation;
- atomic import and deterministic export;
- immutable lock-protected event-tap snapshots;
- event-tap recovery and Accessibility installation retry;
- profile recording suspends global shortcut swallowing.

### Durable exact-window MRU

- current-session `(PID, CGWindowID)` identity remains authoritative;
- durable fingerprint uses bundle identifier plus hashes of normalized title/document URL and non-content geometry/workspace metadata;
- raw titles, URLs, previews, screenshots, search queries, and clipboard content are not stored;
- one persisted record may map to only one live window;
- ambiguous duplicate-title matches are rejected;
- current-session activations outrank restored records;
- records expire after 45 days by default;
- atomic owner-only persistence under Application Support;
- user-facing durable-history reset.

### Exact-window actions

- restore;
- zoom/maximize;
- fullscreen toggle;
- move to next display;
- centre;
- left/right half tiling;
- first/centre/last third tiling;
- force quit with explicit confirmation;
- capability checks and disabled unavailable actions;
- frame constraints and exact readback verification;
- membership refresh after successful actions.

## Required environments

At minimum:

- the oldest supported macOS major version;
- the latest supported macOS major version;
- Apple Silicon;
- one multi-display setup with mixed scaling;
- Stage Manager on and off;
- fullscreen and multiple managed Spaces;
- Accessibility and Screen Recording denied, granted, revoked, and re-granted;
- a clean user account for durable profile and history persistence;
- Intel only if an x86_64 artifact is actually claimed.
